# OnSet Gallery

**Высокопроизводительное приложение для отбора и быстрого просмотра фотографий на съёмке для фотографов, диджитал-ассистентов и съёмочных команд.**

[English](README.md) | [Русский](README.ru.md) | [Руководство пользователя](guide.ru.md) | [Лицензия](LICENSE.md) | [Конфиденциальность](PRIVACY.md)

![Интерфейс OnSet Gallery](guide/03-gallery.png)

OnSet Gallery — профессиональное десктопное приложение для быстрого отбора и контрольного просмотра кадров непосредственно во время съёмки. Создано для студийных, репортажных и выездных фотографов, диджитал-техников (digitechs) и ассистентов. Приложение устраняет задержку между съёмкой и постпродакшном.

Размечайте, оценивайте и фильтруйте сотни и тысячи кадров в процессе съёмки, а затем мгновенно передавайте результаты в виде стандартных XMP-файлов или списков имён в **Adobe Lightroom Classic** и **Capture One Pro** — полностью оффлайн, без задержек и без облачных сервисов.

---

## Ключевые возможности

- **100% оффлайн и приватность:** Полностью локальная работа. Без регистрации аккаунтов, без телеметрии, без аналитики и без выгрузки в облако. Фотографии и метаданные никогда не покидают ваш компьютер.
- **Мгновенная работа с RAW и JPEG:** Отображение встроенных превью высокого разрешения из RAW-файлов и стандартных JPEG без ожидания ресурсоёмкого дебайеринга (demosaic) прямо во время съёмки.
- **Эргономичная клавиатурная навигация:** Быстрая расстановка меток, звёзд (1–5), лайков и отклонений нажатием одной клавиши.
- **Умный локальный предотбор (Pre-Cull):** Локальный алгоритмический анализ серийных дублей, автоматически выявляющий технический брак (смаз, промах фокуса, закрытые глаза / неудачную мимику на macOS) с сохранением лучших дублей и ручных меток.
- **Встроенный FTP-приёмник:** Беспроводной приём кадров по Wi-Fi напрямую с камер (Sony, Canon, Nikon и др.) в папку текущей сессии.
- **Неразрушающий обмен метаданными:** Генерация стандартных `.xmp` сайдкаров или запись тегов в метаданные JPEG без изменения исходных RAW-файлов и без сброса ранее сделанной проявки.

## Зачем нужен OnSet Gallery

На коммерческих съёмках, в студии и на динамичных мероприятиях удачные дубли видны сразу, однако спустя несколько часов поиск тех же кадров в общем каталоге превращается в долгий разбор сотен однотипных файлов.

OnSet Gallery работает в момент фиксации кадра:

1. **Контрольный просмотр при съёмке:** По мере поступления файлов по Wi-Fi FTP или через подключение камеры режим «Следить» сразу выводит новые кадры на экран ноутбука или внешний монитор для клиента.
2. **Командная работа на площадке:** Передайте ноутбук или планшет заказчику, арт-директору или ассистенту для отметки фаворитов во время пауз, не рискуя настройками каталога и целостностью файлов.
3. **Бесшовный перенос в Lightroom и Capture One:** Экспортируйте разметку в виде XMP-файлов или скопируйте список имён. Откройте каталог, синхронизируйте метаданные и сразу начинайте обработку отобранных файлов.

## Сводка функций

| Функция | Описание |
| --- | --- |
| **Клавиатурный отбор** | Перемещение `←` `→`, лайк (`↑`), отклонение (`↓`), избранное (`F`), рейтинг (`1`–`5`), отмена последнего действия (`Z`). |
| **Режимы ленты** | Фильтрация: Все, Неотмеченные, Лайки, Избранное, Отклонённые. Автоматический пропуск или скрытие брака при листании. |
| **Обзорная сетка (Grid)** | Быстрое переключение между просмотром одного кадра и общей сеткой серии (`G`) с масштабированием миниатюр. |
| **Умный предотбор серии** | Локальный расчёт дублей внутри сессии для выявления смазов, расфокуса и технического брака. |
| **Универсальный экспорт** | Запись `.xmp` рядом с исходниками, упаковка в архив `.xmp.zip` для передачи на другой компьютер или копирование списка имён в буфер обмена. |
| **Совместимость с каталогами** | Полное соответствие метаданным **Adobe Lightroom Classic** и **Capture One Pro** (зелёная метка = лайк, жёлтая = избранное, красная метка и статус rejected = отклонён; рейтинг 1–5 звёзд). |
| **Встроенный FTP-сервер** | Выделенный локальный FTP-сервер (`:2121`) для прямой беспроводной передачи кадров с камеры по Wi-Fi. |

## Схема рабочего процесса

```
  Камера (Wi-Fi FTP / проводной перенос)
             │
             ▼
  Папка съёмки на диске (RAW / JPEG)
             │
             ▼
     OnSet Gallery
  (Быстрый отбор • Предотбор дублей • Рейтинги)
             │
             ├──► XMP-сайдкары (.xmp)
             ├──► Архив с метаданными (.xmp.zip)
             └──► Список отобранных имён (буфер обмена)
             │
             ▼
  Adobe Lightroom Classic / Capture One Pro
  (Немедленная обработка отобранных кадров)
```

1. **Создание сессии:** Откройте папку со съёмкой (`Ctrl+O` / `⌘O`).
2. **Просмотр и разметка:** Листайте и оценивайте кадры с клавиатуры. Включите клавишей `Space` режим «Следить», если камера передаёт кадры во время съёмки.
3. **Предотбор (опционально):** Запустите анализ длинных серий, чтобы программа автоматически пометила явный технический брак.
4. **Экспорт метаданных:**
   - Нажмите **Экспорт** и выберите запись XMP или копирование списка имён.
   - В **Lightroom Classic**: выделите папку съёмки и выберите **Metadata → Read Metadata from Files** (или отфильтруйте файлы по скопированному списку).
   - В **Capture One**: включите автоматическую синхронизацию XMP в **Preferences → Image** (или выберите **Select → Select By → Filename List**).

Подробное пошаговое руководство со скриншотами: **[Инструкция (guide.ru.md)](guide.ru.md)**.

## Установка и системные требования

Готовые сборки для **macOS** и **Windows** доступны на странице релизов GitHub:

👉 **[Скачать актуальный релиз](https://github.com/konubrikov/onset-gallery/releases)**

| Платформа | Пакет | Архитектура | Системные требования |
| --- | --- | --- | --- |
| **macOS** | DMG | Universal (Apple Silicon и Intel) | macOS 12 Monterey или новее |
| **Windows** | MSI / Исполняемый EXE | x64 (64-bit) | Windows 10 или 11 (64-bit) |

### Установка на macOS

1. Загрузите файл `.dmg` со страницы [Релизов](https://github.com/konubrikov/onset-gallery/releases).
2. Откройте образ `.dmg` двойным кликом.
3. Перетащите **OnSet Gallery** в папку **«Программы» (Applications)**.
4. **Первый запуск и предупреждение macOS Gatekeeper:**
   - Поскольку тестовые сборки распространяются напрямую без сертификата Apple Developer ID, служба безопасности macOS Gatekeeper может показать предупреждение: *«Не удается открыть приложение OnSet Gallery, так как не удалось проверить разработчика»* или *«Apple не может проверить его на наличие вредоносного ПО»*.
   - **Способ 1 (через Finder):** Откройте папку **«Программы»**, нажмите правой кнопкой мыши (или с зажатой клавишей `Control`) на иконку **OnSet Gallery** и выберите **«Открыть»**. В появившемся окне подтверждения нажмите **«Открыть»**. Это подтверждение требуется только при первом запуске.
   - **Способ 2 (через Терминал):** Если система блокирует запуск, снимите флаг карантина macOS командой:
     ```bash
     xattr -cr /Applications/OnSetGallery.app
     ```

### Установка на Windows

1. Загрузите установщик `.msi` или исполняемый `.exe` со страницы [Релизов](https://github.com/konubrikov/onset-gallery/releases).
2. Запустите файл и выполните шаги мастера установки.
3. **Первый запуск и предупреждение Windows Defender SmartScreen:**
   - Для тестовых сборок без коммерческого EV-сертификата фильтр Windows Defender SmartScreen может показать синее окно защиты: *«Система Windows защитила ваш компьютер»*.
   - Нажмите ссылку **«Подробнее»** (More info) в тексте сообщения.
   - Нажмите появившуюся кнопку **«Выполнить в любом случае»** (Run anyway).
   - Приложение запустится в штатном режиме.

## Хранение данных и конфиденциальность

- **Локальное хранилище:** Индексы сессий, кэш превью и метки хранятся локально в директории `~/.onset-gallery/` (или `%USERPROFILE%\.onset-gallery` на Windows).
- **Сохранение исходников:** Удаление сессии в OnSet Gallery очищает только локальный рабочий кэш программы. Исходные файлы съёмки в целевой папке никогда не удаляются и не изменяются.
- **Отсутствие телеметрии:** Приложение не выполняет скрытых сетевых запросов, не собирает аналитику и не обращается к облачным серверам.

Подробнее в документе **[Политика конфиденциальности (PRIVACY.md)](PRIVACY.md)**.
